PRAAN - ASI validation against observed growth
==============================================================================

Question: does the Absorption Stress Index correspond to how Dhaka
wards actually grew between 2000 and 2020?

Observed data: WorldPop annual population and JRC GHSL built-up
surface, extracted per ward over the same boundaries used for the
ranking.

ASI vs observed population growth 2000-2020
  n = 75   Spearman rho = +0.267 (p = 0.0203)   Pearson r = +0.309
  -> higher-stress wards grew faster; significant at p < 0.05. Endogenous - see 20_predictive_validation.py
ASI vs observed built-up growth 2000-2020
  n = 75   Spearman rho = -0.487 (p = 0.0000)   Pearson r = -0.230
  -> lower-stress wards grew faster; significant at p < 0.05. Endogenous - see 20_predictive_validation.py
Crisis Index vs observed population growth
  n = 75   Spearman rho = +0.258 (p = 0.0252)   Pearson r = +0.287
  -> higher-stress wards grew faster; significant at p < 0.05. Endogenous - see 20_predictive_validation.py

WHY THIS DOES NOT SETTLE THE ALLOCATION RULE
------------------------------------------------------------------------------
These correlations use the PRESENT-DAY ASI, whose largest component
is present-day population density. A ward is dense today partly
BECAUSE it grew over this very period, so the outcome sits inside
the predictor and a positive rho here is not evidence that stress
attracts arrivals.

The allocation rule is decided by 20_predictive_validation.py, which
rebuilds the index from year-2000 inputs only. It finds no predictive
relationship in any window, so arrivals are allocated on population
alone. An index that fails its own validation, reported honestly, is
worth more than one that was never tested.
